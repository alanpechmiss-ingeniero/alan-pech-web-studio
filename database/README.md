# Base de datos

Por autorización del propietario, este repositorio versiona el respaldo completo en `ecommerce.sql`. Puede contener cuentas, contraseñas cifradas u otros datos reales; el repositorio debe permanecer privado.

Importa `ecommerce.sql` en MySQL/MariaDB desde phpMyAdmin o la línea de comandos.

Para compartir la estructura de forma segura, coloca archivos SQL sin datos reales en `database/schema/`. Esos archivos sí se incluirán en Git.

La configuración de conexión local está excluida en `api/models/connection.php`; no la subas a GitHub.
