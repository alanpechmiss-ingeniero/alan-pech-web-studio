# Alan Pech Web Studio

Portafolio y demostración de servicios de desarrollo web: sitios corporativos, tiendas en línea y sistemas de punto de venta.

## Incluye

- Portada profesional adaptable a celular, tablet y escritorio.
- Servicios de desarrollo web, e-commerce y POS.
- Llamadas a la acción por correo electrónico.
- Metadatos básicos para compartir el proyecto en redes sociales.
- Fallback visual para abrir la portada sin una API o base de datos configurada.

## Uso local

1. Coloca la carpeta `web` en un servidor compatible con PHP.
2. Ajusta la URL base según tu entorno en `web/controllers/template.controller.php`.
3. Para habilitar el catálogo y la administración, configura una API y una base de datos propias. Nunca subas credenciales ni información de clientes al repositorio.
